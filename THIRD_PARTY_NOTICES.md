# Third-party dependencies

This repository bundles unmodified Python wheel distributions in `wheels/` for offline installation on 64-bit Windows with Python 3.12. Each distribution retains its upstream metadata, copyright notices, and license files within the wheel archive.

The authentication implementation is provided by **NEU-ipgw-manager 3.3**, copyright (c) 2019-present Luo Bendong (Neboer), distributed under the MIT License. Its complete license is included in `neu_ipgw_manager-3.3.dist-info/licenses/LICENSE` within its wheel.

The wheel bundle also contains requests, tabulate, beautifulsoup4, wcwidth, platformdirs, soupsieve, typing_extensions, charset_normalizer, idna, urllib3, and certifi. Their respective upstream licenses continue to apply; no ownership of these packages is claimed by this project.
